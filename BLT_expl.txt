1. Bank Account Management

Aim: Create a simple banking smart contract that allows users to deposit, withdraw and check balance.

Your contract name is SimpleBank.

Important code explanation:
address public owner;
uint256 public balance;

- address owner stores the owner's blockchain address.
- uint256 balance stores the account balance.
constructor() {
    owner = msg.sender;
    balance = 0;
}

- Constructor runs only once when the contract is deployed.
- msg.sender represents the address that deploys the contract.

Main functions:
- deposit() – Adds money to the balance.
- withdraw() – Subtracts money from the balance.
- getBalance() – Returns the current balance (if present in the implementation).

2. Student Marks Management System

Aim: Store student details and manage their marks using a smart contract.

Your contract name is MarksManagmtSys.
Understand the code
1. Structure
struct Student {
    uint id;
    string fName;
    string lName;
    uint marks;
}

A structure groups related student information together.

2. Array
Student[] public stdRecords;

Stores multiple student records.

3. Owner
address owner = msg.sender;

Stores the address of the person deploying the contract.

4. Modifier
modifier onlyOwner() {
    require(msg.sender == owner);
    _;
}

- Checks whether the caller is the owner.
- require() checks a condition.
- _ means execute the original function body.
5. Add records
stdRecords.push(
    Student(id, first, last, marks)
);

Adds a new student record to the array.

6. View marks
function viewMarks(uint index)
public view returns (uint)

Returns marks of a particular student.

7. Bonus marks
stdRecords[index].marks += bonus;

Adds bonus marks to the student's existing marks.
