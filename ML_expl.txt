1. Diabetes Prediction
Aim: Predict whether a person is likely to have diabetes using medical input data.

Basic workflow:
1. Import Python libraries.
2. Load the dataset.
3. Check missing values.
4. Separate input features and target.
5. Split training and testing data.
6. Train the ML model.
7. Predict the result.
8. Calculate accuracy.

Viva:
- What is Machine Learning? Teaching computers to learn patterns from data.
- What is a dataset? A collection of data.
- What is classification? Predicting a category or class.
- What is accuracy? Percentage of correct predictions.
- What is training data? Data used to train a model.
- What is testing data? Data used to evaluate a model.
